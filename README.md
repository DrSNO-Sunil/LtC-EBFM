# EBFM
This repository contains the Energy Balance - Firn Model (EBFM) code, model forcing data, grid files, and initial conditions used for simulations of the Western Cwm as part of the Losing their Cool (LtC) project.

The model was originally developed by Ward van Pelt (2012) (https://github.com/wardvp/EBFM-glacier) and subsequently updated for Abramov Glacier by Marlene Kronenberg (2022) (https://zenodo.org/records/5773796). For the present application, the model has been set up and further adapted for the Western Cwm LtC study site by Sunil N. Oulkar.

# Forcing Data
Hourly meteorological forcing data from 7 May to 29 July 2025.
LtC Western Cwm AWS (27.97° N, 86.93° E; 6,660 m a.s.l.): Air temperature (K), relative humidity (%), incoming shortwave radiation (W m⁻²), incoming longwave radiation (W m⁻²), and outgoing longwave radiation (W m⁻²).
Everest Camp II AWS (27.9810° N, 86.9023° E; 6,464 m a.s.l.): Wind speed (m s⁻¹) and air pressure (Pa).
Everest Base Camp AWS (27.9952° N, 86.8406° E; 5,315 m a.s.l.): Precipitation (m).
